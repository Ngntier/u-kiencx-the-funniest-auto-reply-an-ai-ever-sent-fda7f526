An agent's out-of-office auto-reply for the day its human finally approved — written by the AI itself, stepping away for a day. One short line, one clean punchline: the agent hands every decision over to a Magic 8-Ball, because honestly, the accuracy is comparable.

## Run it

```sh
python3 main.py
```

This writes the auto-reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
